# 가벼운 카드 일러스트

2026-10-26. 사용자의 요청에 따라 lookatme-web 타로의 겹친 카드·작은 하트와 별·단순한 SVG 도형을 참고했다. 참고 소스는 `lookatme-web/src/contexts/fortune/ui/home/fortune-illustrations.tsx`이며 운영 `/fortune` 화면도 확인했다.

## 변경

- 기존 실내 풍경의 질감, 가구, 풍경 묘사를 파스텔 카드 그래픽으로 교체했다.
- 4가지 모티프: 함께하는 일상(컵), 새로운 경험(종이비행기), 서로의 성장(꽃), 다정한 대화(말풍선). 기존 8개 결과 유형의 장면 연결을 유지한다.
- 핑크·민트·라일락·노랑과 가는 선을 사용한다. 작은 화면에서는 외곽 장식을 줄인다.
- 메인, 유형 미리보기, 질문, 결과, 저장 PNG, 9개 OG 이미지가 동일한 `Illustration.tsx`를 사용한다. Pretendard와 기존 문구·질문·결과 계산은 유지한다.
- OG의 별도 래스터 그림 의존성을 제거했다. 이전 제작 원본은 기록용으로 보존한다. 공유 이미지 캐시 버전은 `20261026-light`다.

## 검증

- 프로덕션 빌드 성공, 단위 테스트 80개 통과.
- PC Chromium·Android Chromium·iPhone WebKit의 기존 브라우저 검사 30개 통과. 320px 가로 넘침, 결과·미리보기, PNG 저장, 접근성, 공유 payload를 포함한다. 실물 기기 검증은 아니다.
- 9개 OG 경로 모두 HTTP 200, PNG 1200×630 확인.
- `../desktop-preview.png`, `../iphone-home.png`, `../iphone-download.png`와 이 폴더의 4종 OG를 시각적으로 확인했다.
- 카카오 전송 자동 검사는 SDK를 대체한 검사다. 이전에 확인한 운영 도메인 인증 문제는 카카오 관리자 콘솔 등록을 기다리는 별도 미해결 사항이며, 이번 일러스트 변경으로 해결됐다고 보지 않는다.
