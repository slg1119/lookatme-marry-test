# lookatme-marry-test

**어떤 사람과, 어떤 매일을 함께할까요?**

`marry-test`는 결혼을 생각하는 사람들을 위한 한국어 관계 취향 테스트입니다. 나의 생활 방식과 원하는 상대를 따로 살펴보고, 결과를 실제 만남에서 나눌 이야기로 연결합니다.

![marry-test 첫 화면](qa/desktop-preview.png)

## 실행

Node.js 22.12 이상이 필요합니다.

```bash
npm ci
npm run dev
```

기본 주소는 `http://localhost:4173`입니다.

```bash
npm run build       # TypeScript 검사 + 정적 배포 파일 생성
npm run preview     # 빌드 결과 미리보기
npm test            # 계산 로직 단위 테스트
npm run test:e2e    # PC / Android / iPhone 브라우저 시나리오
```

브라우저 테스트를 처음 실행할 때는 `npx playwright install chromium webkit`으로 테스트 브라우저를 설치합니다.

## 구현된 경험

- 회원가입 없이 답하는 12개 생활 장면 질문. 앞 6개는 나의 모습, 뒤 6개는 원하는 상대입니다.
- 일상, 함께 보내는 시간, 마음을 나누는 방식의 세 축과 8가지 결혼 스타일.
- 답변 수정, 진행 저장 및 이어하기, 새로 시작하기.
- 배우자 선호 설명과 첫 만남에서 나눌 대화 질문 3개.
- 직접 제작한 SVG 일러스트 4종과 모바일 반응형 화면.
- 결과 카드 PNG 저장, Web Share API, 클립보드와 수동 복사 대안.
- 공유 링크에서는 일반 유형 소개만 보이며 개인 답변이나 상대 선호는 포함하지 않습니다.
- 룩앳미 사이트 연결. 신청·결제·회원 연동은 포함하지 않습니다.

## 설정

`.env.example`을 참고하여 `.env.local`에 연결할 소개팅 사이트 주소를 설정할 수 있습니다.

```env
VITE_MEETING_URL=https://www.lookatme.my
```

Vite 환경 변수는 빌드 시 포함되므로 변경 후 다시 빌드합니다. `dist/`를 정적 호스팅으로 제공할 수 있습니다. 라우팅은 해시 기반이라 공유 결과에 별도 서버 라우팅이 필요하지 않습니다. 로컬 주소로 만든 공유 링크는 같은 컴퓨터에서만 열 수 있으며, 외부 공유에는 공개 호스팅이 필요합니다.

## 데이터와 결과

답변은 현재 탭의 `sessionStorage`에만 저장합니다. 서버, 분석 도구, 외부 AI로 답변을 전송하지 않습니다. 저장소를 사용할 수 없는 환경에서도 현재 테스트는 동작합니다. 처음부터 다시 시작하면 이전 답변을 지웁니다.

`src/lib/quiz.ts`에서 질문·유형·계산 규칙을 관리합니다. 자기 성향과 원하는 상대는 별도로 계산합니다. 동점은 균형으로 설명하며, 유형 이름에만 일관된 기준을 적용합니다. 이 서비스는 대화와 자기 탐색을 위한 콘텐츠로, 정식 MBTI 검사·심리 진단·결혼 성공 가능성의 예측 도구가 아닙니다.

## 디자인

따뜻한 종이색, 버건디와 올리브, 한국어 명조 제목, 직접 그린 일상 장면을 사용했습니다. 폰트는 설치 패키지에서 자체 제공하며 외부 폰트 서비스에 의존하지 않습니다. 키보드 조작, 모달 포커스, 동작 줄이기 설정을 지원합니다.
